# 현재 프로그램 사태
현재 프로젝트의 기능사항은 다음과 같음

애초에 사용될 양식이 정해져 있음 (이카운트 양식, 네이버 양식, 카카오 양식, 쿠팡양식, 일괄양식)


# 불편한점 
하지만 프로그램을 사용하면서 느낀점은 사용되는 온라인 플랫폼이 자꾸 바뀌기 때문에 이렇게 사용되는 양식을 하나하나 정해놓고 하지 말고
유동적으로 사용자가 사용될 양식을 파일을 정할 수 있도록 하면 좋겠음
다만, 큰 카테고리는 설정 탭 내에서 하위 탭으로 다음과 같이 분류될 수 있었으면 좋겠음
 - 주문정보양식파일
 - 송장파일
 - 내보내기파일
 - 일괄양식파일

이렇게 나눈 이유는 주문정보 파일과 일괄양식 파일은 온라인 플랫폼별로 양식이 다르기 때문임.

# 최종 요구 기능

- 프로그램 UI 형태
    설정탭
        주문정보파일 탭: 이탭 하위에 사용자가 동적으로 이름을 정하고 해당하는 엑셀 파일을 드래그 엔 드롭하여 양식을 설정할 수 있다.
        예를 들어 사용자가 주문정보양식파일 추가 버튼을 누르고 이름을 입력하고 네이버 스마트 스토어에서 다운받은 주문정보양식파일을 프로그램에 드로그 엔 드롭하면 자동으로 엑셀파일의 헤더를 읽어 양식을 설정해주는 방식이다.
        이때, 사용자가 설정해야 해 줄 부분이 있는데 그것은 바로 양식 이름과, 각 양식으 헤더가 몇 번쨰 줄인지와, 양식의 각 속성들이 송장 파일에 어떤 속성에 매핑되는지에 대한 정보다. 결국에는 각 각 양식 모두 송장 파일로 변환될 것이고, 송장 파일에 있는 양식을 모두 갖고 있지만 각기 속성이름이 조금씩 다르기 때문에 이에 대한 매핑이 필요하다. 예를 들어 네이버 스마트스토어에서 다운받은 주문정보양식파일의 수취인은 송장양식파일의 수하인 명과 매핑이 되고, 주문정보양식파일의 통합배송지라는 속성은 송자양식파일의 수하인주소라는 속성과 매핑이 되야 하는 것을 사용자가 직접 정해주는 것이다.

        송장파일 탭: 이탭 하위에 사용자가 동적으로 이름을 정하고 해당하는 엑셀 파일을 드래그 엔 드롭하여 양식을 설정할 수 있다. 다만 이 탭은 양식을 하나만 설정할 수 있게 하기

        내보내기파일 탭: 이탭 하위에 사용자가 동적으로 이름을 정하고 해당하는 엑셀 파일을 드래그 엔 드롭하여 양식을 설정할 수 있다.  다만 이 탭은 양식을 하나만 설정할 수 있게 하기

        일괄양식파일 탭: 이탭 하위에 사용자가 동적으로 이름을 정하고 해당하는 엑셀 파일을 드래그 엔 드롭하여 양식을 설정할 수 있다.  
        이때, 사용자가 직접 매핑해줘야 할 부분이 있음
        예를 들어 네이버 일괄양식의 속성이 상품주문번호, 배송방법, 택배사, 송장번호 라면, 상품 주문번호는 네이버 스마트 스토어에서 다운받은 주문정보파일에서는 상품주문번호를, 송장번호는 내보내기 파일에 있는 운송장 번호가 쓰일 것임
        즉, 일괄양식을 설정할 때는 사용자가 어떤 주문정보파일을 참조할지, 각 일괄양식의 속성은 어떤 양식의 어떤 속성을 참조할지 정해주어야 함. 근데 송장번호는 항상 내보내기파일에서 참조하고 내보내기 파일의 종류는 하나로 고정되니까, 사용자가 설정할 파일은 주문정보파일뿐임
